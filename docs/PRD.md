# AI 视频创作工作台（个人自用版 · 对标 MiniMax H3）PRD 与 Google 全家桶架构方案（v2.0）

## 1. 产品定位
本工具面向个人创作者自用，对标 **MiniMax H3 + MiniMax Design** 的核心创作理念，去掉多租户、支付与无限画布等高维护复杂度功能，采用 **Local-First（本地优先）+ Google AI 全家桶** 架构，实现：
- **零云端服务器/存储费用**：程序、SQLite 数据库、素材、分镜和 FFmpeg 合片全部运行在本地 Windows 电脑，预算 100% 投入到模型调用。
- **高效三栏导演台**：左侧 AI 导演对话与 Skills，右侧三大聚焦视图（资产库 / 结构化分镜故事板 / 轻量多轨合片时间线）。
- **最大化利用 Google AI Ultra 权益**：
  1. 使用 Ultra 附带的每月 **$40（5x）/ $100（20x）** 开发者抵扣金调用 Gemini API / Vertex AI。
  2. 提供 **Google Flow 创作包一键导出 + 本地拖入 Take** 桥接，便于将 Ultra 附带的 **25,000 点 Flow 网页端积分** 与本地工程无缝打通。

## 2. 核心功能模块

### 2.0 小说导入与自动拆集拆镜引擎（Novel Studio）
- 支持上传 `.txt`（自动兼容 UTF-8 / GB18030 / GBK 中文编码）、`.md`、`.docx`、`.epub` 整本小说文件，或直接粘贴长文本。
- **两级自动拆分**：
  1. **物理拆集**：自动识别中英文章节标题（`第X章/回/节`、`Chapter X`、`序章/楔子` 等），超长章节按段落边界自动切分；也支持按设定字数（默认 2000 字/集）均分。
  2. **Gemini 1M 长上下文提取全书设定（Book Bible）**：一次性通读多章提取全书统一的**角色档案、高频场景、关键道具**并写入资产定妆库，确保第 1 集到第 N 集主角不崩脸。
  3. **按集拆镜**：选择任意分集按需拆解为结构化分镜（自动带入上一集梗概衔接剧情，自动绑定全书 `@资产`），并支持在分镜板与时间线中按分集筛选与分集导出成片。

### 2.1 项目与资产一致性中心（Asset Hub）
- 本地文件夹隔离每个项目（`data/projects/<project_id>/`）。
- 支持管理角色（Character）、场景（Scene）、道具（Prop）、音频（Audio）资产。
- 支持文字特征档案（Character Bible）、上传参考图、使用 `gemini-3.1-flash-image`（Nano Banana 2）直接生成定妆图，以及一键生成**角色三视图（Skill）**。
- 分镜与对话支持引用资产，自动将参考图与外貌约束注入关键帧生成管线。

### 2.2 AI 导演智能体（Director Agent）
- 输入一句话灵感或剧本，自动拆解为结构化分镜表（镜头号、景别、运镜、画面描述、英文影视提示词、时长、台词、音效提示、关联资产）。
- 支持对话式局部修订（修改特定镜头景别、灯光、台词或整体风格）。
- **防烧钱确认闸门**：AI 生成分镜提案后由用户预览确认再应用；每次图片/视频/音乐生成均明确标注预估美元花费。
- **自动审片质检**：视频生成后调用 Gemini 多模态看片打分，指出穿帮风险并给出提示词改进建议。

### 2.3 结构化分镜故事板（Storyboard）
- 支持**卡片宫格视图**与**脚本表格视图**切换。
- 支持按镜头管理：
  - 首帧关键帧（支持多资产融合生成，也可一键提取上一镜尾帧作为本镜首帧保持连贯）
  - 尾帧关键帧（用于首尾帧过渡生成）
  - 多版本抽卡管理（Takes）：保留多个候选视频、同屏切换对比、一键锁定入选 Take
  - 引擎与档位选择：
    - `veo-3.1-lite-generate-001`（~$0.05/s，低成本打样）
    - `veo-3.1-fast-generate-001`（~$0.12/s，常规均衡）
    - `veo-3.1-generate-001`（~$0.40/s，影视精渲）
    - `gemini-omni-1.2-flash`（Gemini API 对话式全模态生成）
  - **Flow 桥接**：一键复制该镜电影级英文提示词并获取首帧路径；支持把外部下载的 MP4 拖入该镜作为新 Take。

### 2.4 音频、时间线与本地合片导出（Timeline & Export）
- 调用 `lyria-3-clip-preview` / `lyria-3-pro-preview` 生成 48kHz 立体声定制 BGM，也支持导入本地音乐。
- 自动汇总各镜头已锁定的 Take，支持起止裁剪（Trim）、顺序调整、BGM 音量比例与基础淡入淡出、SRT 字幕编辑与烧录。
- 本地 **FFmpeg**（自动兼容系统 FFmpeg 或内置 `imageio-ffmpeg`）一键拼接混音导出 720p / 1080p MP4。

### 2.5 本地预算管家（Budget Guard）
- 本地 SQLite 实时记录每次真实 API 调用的估算成本。
- 顶部常驻月度预算进度条（默认按 Ultra $40 或 $100 配置），超额预警。

## 3. 技术选型（适配本地 Windows Node 18.16 + Python 3.11 环境）
- **前端**：Vite 5 + React 18 + TypeScript + Tailwind CSS v3 + Lucide Icons（兼容 Node 18.16，秒级热更新，零 SSR 复杂度）。
- **后端**：Python 3.11 + FastAPI + SQLAlchemy (SQLite) + `google-genai` SDK + `imageio-ffmpeg` + Pillow。
- **运行模式**：
  - **Live Mode**：配置 `GEMINI_API_KEY`（Gemini API）与可选 GCP Vertex AI 凭据（用于 Veo 3.1 GA）。
  - **Demo Mode**：未配置密钥时自动或手动切换演示模式，本地生成真实占位图与测试 MP4，完整验证所有交互、队列与 FFmpeg 合片链路。
